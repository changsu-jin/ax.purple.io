## Purple AX

Purple AX는 purpleio의 전사 기술 혁신 조직 AX TF입니다. 기술로 비즈니스 운영 방식을 바꾸는 것을 목표로 합니다.

현재 7개의 내부 프로젝트와 2개의 오픈소스 프로젝트를 진행하고 있습니다.

### 내부 프로젝트

**Purple Skills** — 전사 AI 에이전트 스킬 표준화. 40개 이상의 AI 코딩 에이전트에 사내 규칙을 자동 적용합니다.

**Purple Gauge** — 성능테스트 셀프서비스 플랫폼. 운영 메트릭을 베이스라인으로 자동 설정하고, 개발팀이 직접 성능테스트를 실행합니다.

**Purple Hub** — 운영 도메인 지식 허브. AI 에이전트가 비즈니스 맥락을 이해하고 활용할 수 있도록 도메인 지식을 구조화합니다.

**Chatbot (가칭)** — 운영 문의 대응 자동화. RAG 기반 문의 답변과 NL2SQL 데이터 조회를 하나의 대화로 통합합니다.

**E2E (가칭)** — No-Code E2E 테스트 자동화 플랫폼. 코드 없이 테스트 시나리오를 작성하고, AI 실패 진단과 MCP 연동을 지원합니다.

**Purple Mux** — 웹 기반 터미널 + Claude Code 통합 환경. 실시간 AI 상태 모니터링과 업무 도구 통합을 지원합니다.

**Talos (가칭)** — AI 기반 개발 자동화 파이프라인. 현업 요청부터 설계, 구현, 테스트, 배포까지 AI 에이전트가 수행합니다.

### 오픈소스

**MeetNote** — 로컬 회의 녹음 자동 전사 및 AI 요약 Obsidian 플러그인.

**SecondBrain** — Git 동기화와 Claude AI 분석을 결합한 Obsidian 플러그인.
